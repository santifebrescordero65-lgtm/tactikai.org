The GPT generates. Claude generates and remembers.

04 — The Live API

Callable from Claude today. No new infrastructure needed.

The same endpoint the ChatGPT Action calls is callable from Claude's tool_use with no modification to the API. The engine is provider-agnostic.

# Claude tool_use → Tactik Debrief API POST https://tactik-debrief-buddy.lovable.app/api/public/debrief X-Tactik-Key: {api_key} Content-Type: application/json { "transcript": "{conversation | document | chat_export}", "input_type": "conversation | document | chat | research | mixed", "subject_hint": "Person, company, deal, or topic being analyzed", "vertical": "negotiation | diplomacy | education | legal | agro", "source": "claude", "objective": "What the operator wants to achieve next" } → Returns: { markdown, dna, pcg, success_probability, url, id, public_token }

The source: "claude" flag tells the engine the caller is Claude — enabling Claude-specific rendering and the file-write accumulation path. The GPT sets source: "gpt". Claude sets source: "claude" and also writes the result back to the operator model.

05 — The MCP Path

One MCP server. Every Claude surface. Zero context switching.

The next step beyond Claude Code is an MCP server — mcp-tactik-debrief — that exposes the full TACTIK debrief engine as a native tool callable from any Claude client: Claude Desktop, Claude.ai, Claude API, Claude Code.

MCP Tool · generate_debrief

generate_debrief(transcript, subject, vertical, objective)

Returns the full TACTIK READOUT: Decision Intelligence %, DNA extraction, PCG scores, Risks, Your Next Challenge. Updates operator model if session context is active.

MCP Tool · get_operator_dna

get_operator_dna(operator_id)

Loads the accumulated Cognitive DNA of the operator — Layer 1 through Layer 9, SESSION LEDGER, active context — so any Claude session starts with full context, not zero.

MCP Tool · update_operator_model

update_operator_model(session_delta, key_insight, open_questions)

Appends a SESSION LEDGER entry to the operator model. The compounding mechanism. Called automatically by /brief; callable manually by any Claude session that produces a key insight.

TACTIK already has a production MCP server (mcp.tactikai.org) serving institutional simulation tools. The debrief MCP is the same architecture, same server, new tool set. Build time: one sprint.
