02 — The Product

TACTIK Deep Live. Live in production today.

Deep Live is a decision-intelligence engine at tactikai.org. It ingests any Google input — a Gmail thread, a Doc, a Drive PDF, a Meet transcript — and returns a structured, auditable debrief: decision graph, actor-incentive scoring, failure-cascade, red-team counterfactuals. Grounded in proprietary Cognitive DNA, with source citations and confidence scoring.

🧬

Cognitive DNA

Forensic behavioral reconstruction of every actor — not roleplay, not guessing. N1/N2/N3 fidelity tiers.

📊

Decision Graph

Maps the causal structure of the decision: nodes, dependencies, critical paths.

⚠️

Failure Cascade

Projects what happens if the decision breaks at each dependency node, with probability weighting.

🔴

Red-Team

Adversarial stress-testing of the decision logic — the best arguments against the plan, surfaced first.

🎭

Actor Scoring

Maps every stakeholder's incentive structure, objection vectors, and hidden constraints.

🔖

Audit Trail

Every claim is grounded with evidence and confidence scoring. Not a chatbot — a forensic record.

03 — The API

The Tactik Debrief engine is callable today.

The engine is already deployed as a live API at tactik-debrief-buddy.lovable.app — callable by any LLM surface. The custom GPT "Tactik Debrief" (by Santiago Maspons) uses it in production via a ChatGPT Action.

# Live endpoint — callable from any surface POST https://tactik-debrief-buddy.lovable.app/api/public/debrief X-Tactik-Key: {api_key} Content-Type: application/json { "transcript": "{gmail_thread | doc_content | meet_transcript}", "input_type": "conversation | document | chat | research", "subject_hint": "Who or what is being analyzed", "vertical": "negotiation | diplomacy | education | legal", "objective": "What the operator wants to achieve next" } → Returns: { markdown, dna, pcg, success_probability, url }

The conversation starters in the live GPT make the Google integration explicit:

Google Meet Aquí va la transcripción de mi reunión — hazme el debrief.
Gmail Te paso este hilo de emails — analiza cómo razoné.
Google Docs Adjunto este documento — ¿cómo estuvo mi razonamiento?
Opal / Chrome Sesión capturada — genera el TACTIK READOUT.

Every Google surface already maps to an input type. The engine is running today.

07 — The Honest Gap

One primitive we need from Google's side.

The API is live. The engine runs. There is one missing primitive on the Opal side that would make this a first-class Google integration — not a workaround.

The Ask — 30 Minutes

1
One authenticated POST primitive. Opal's Tool node can fetch web pages. What Deep Live needs is a first-class primitive: an authenticated POST-with-JSON call to an external endpoint that returns structured JSON back. That single primitive closes the loop.
2
Native Workspace connectors as first-class Opal tool inputs — Gmail threads, Docs, Meet transcripts — feeding directly into the decision engine without intermediate parsing steps.
3
30 minutes. We demo the production endpoint live. You tell us whether that primitive exists or whether this is the use-case for building it.
