# LinkedIn post — "The model can argue perfectly and never make an offer"

## Post (English)

The model can argue perfectly and never make an offer.

We ran a full negotiation on our own platform, end to end, the way a user would.

Nine turns against an AI counterparty.

It knew the regulation. It knew the commercial pressure. It pushed back on every point.

And in nine turns, it never once named a price, a volume, a date or a term.

Every reply opened the same way: restate my position, then attack it.

Fluent. Well-informed. Impossible to negotiate with.

That is not a style problem. It is structural.

A language model cannot hide a limit from itself. Whatever it knows about its own walk-away point, it knows in the same place it speaks from. So under pressure it gives the limit away — or it behaves as if it has none.

Either way, there is nothing to score.

So we hold one rule: the model that speaks never holds the limits.

We measured the correction in a second engine. Turns that put a real term on the table: 0 of 6 before. 5 of 6 after.

Forty years at negotiating tables taught me that an argument is not an offer.

It holds for machines too.

If you rehearse against AI before a real table — does your sparring partner ever make you an offer?
