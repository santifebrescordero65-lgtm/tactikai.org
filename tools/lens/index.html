TACTIK Lens

Chrome extension (Manifest v3 · Side Panel) que captura el contexto de cualquier superficie Google — Gmail, Docs, Meet, Search — e inyecta directamente en Deep Live para análisis.

📌
Side Panel nativo — visible junto a cualquier pestaña de Google Workspace sin interrumpir el flujo.
⚡
Un clic — captura el texto completo de la pestaña activa: hilo de email, documento, notas de reunión.
🧠
Inyección directa — el contexto capturado va directo al motor de decisiones. Sin copy-paste.
🔗
OPAL/Chrome — el starter del GPT "Tactik Debrief": "Sesión capturada — genera el TACTIK READOUT."
✓ Paquete generado correctamente. Descarga iniciada.

Cómo instalar en Chrome

  1. Haz clic en el botón de arriba para descargar el .zip
  2. Descomprime el archivo en una carpeta local
  3. Ve a chrome://extensions/ en tu navegador
  4. Activa "Modo desarrollador" (esquina superior derecha)
  5. Haz clic en "Cargar extensión sin empaquetar"
  6. Selecciona la carpeta descomprimida
  7. El ícono de TACTIK Lens aparecerá en la barra de herramientas
manifest.json — Contenido del paquete
{
  "manifest_version": 3,
  "name": "TACTIK Lens",

  "permissions": ["sidePanel", "activeTab", "scripting"],
  "side_panel": { "default_path": "sidepanel.html" }
